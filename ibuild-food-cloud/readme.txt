نظام قطاع التغذية والكاترنج بواجهة عربية، قاعدة بيانات مركزية، مستخدمين وصلاحيات، وسجل مراجعة.

== Installation ==
1. من إضافات ووردبريس اختر أضف إضافة ثم رفع إضافة.
2. ارفع ملف ibuild-food-cloud-2.15.0.zip وفعّله.
3. افتح I-BUILD Food ثم المستخدمون والصلاحيات وأنشئ الحسابات.
4. افتح النظام من صفحة /ibuild-food/.

- المدير يسنِد للمراجع أكثر من مدرسة عند إنشاء الحساب، والخادم يقصر كل قراءاته على هذه المدارس وحدها.

== Security ==
- لا توجد كلمات مرور افتراضية داخل الواجهة.
- يعتمد تسجيل الدخول على WordPress وكلمات المرور المشفرة الخاصة به.
- كل طلب بيانات يتحقق من الجلسة والصلاحية والموقع على الخادم.
- يسجل النظام عمليات الإنشاء والتعديل والحذف وتغيير الصلاحيات.
