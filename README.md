# نظام I-BUILD الذكي لإدارة النظافة

نسخة أولية قابلة للتشغيل لإدارة أعمال النظافة والمواقع والتفتيش اليومي والمخازن والصلاحيات وحركة السيارات لشركة I-BUILD.

## التشغيل المحلي

```powershell
npm start
```

ثم افتح:

```text
http://127.0.0.1:4180
```

## بيانات الدخول الافتراضية

- اليوزر: `admin@ibuild.local`
- الباسورد: `123456`

## النشر على الإنترنت

المشروع جاهز للنشر كخدمة Node.js. بعد رفعه على GitHub يمكن ربطه بمنصة استضافة مثل Render.

إعدادات النشر:

- Build Command: `npm install`
- Start Command: `npm start`
- Port: يتم قراءته تلقائيا من متغير البيئة `PORT`

يوجد ملف `render.yaml` لتسهيل النشر التلقائي.

## النشر على Netlify

المشروع يحتوي على إعداد Netlify جاهز:

- ملف الإعداد: `netlify.toml`
- مجلد النشر: `public`
- مسار الـ API: `/.netlify/functions/api`
- يتم تحويل `/api/*` تلقائيا إلى Netlify Function

إعدادات Netlify:

- Build command: `npm run build`
- Publish directory: `public`
- Functions directory: `netlify/functions`

ملاحظة: Netlify Functions مناسبة للتجربة. حفظ البيانات داخل Netlify ليس دائما في هذه النسخة، وللعمل الحقيقي يجب ربط قاعدة بيانات خارجية مثل PostgreSQL.

## المكونات

- واجهة عربية RTL متوافقة مع الجوال والتابلت والكمبيوتر.
- لوحة تحكم، مواقع، عقود، تفتيش يومي، خامات، تقارير، صلاحيات، حركة سيارات.
- QR لكل موقع يفتح صفحة التفتيش مباشرة.
- صلاحيات يحددها المدير العام لكل مستخدم.
- شعار I-BUILD داخل النظام.

## ملاحظة

هذه نسخة أولية تستخدم ملف JSON محلي داخل `data/db.json`. عند تشغيلها إنتاجيا يفضل ربطها بقاعدة بيانات PostgreSQL.
