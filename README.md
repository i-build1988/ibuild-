# نظام I-BUILD الذكي لإدارة النظافة

نسخة أولية قابلة للتشغيل لإدارة أعمال النظافة لشركة I-BUILD.

## التشغيل

```powershell
npm start
```

ثم افتح:

```text
http://127.0.0.1:4180
```

## المكونات

- واجهة عربية RTL متوافقة مع الجوال والتابلت والكمبيوتر.
- صفحات رئيسية: لوحة التحكم، المواقع، التفتيش اليومي، الخامات، التقارير، المستخدمون.
- API محلي للتجربة يعتمد على ملف JSON داخل `data/db.json`.
- مخطط PostgreSQL جاهز في `db/schema.sql`.

## المرحلة التالية

- ربط API فعلي بقاعدة PostgreSQL عبر `DATABASE_URL`.
- إضافة تسجيل دخول وجلسات وصلاحيات فعلية.
- توليد QR Code حقيقي لكل موقع.
- تصدير PDF و Excel من الخادم.
